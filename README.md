# OIOL Planner v0.1.0 — Reconstructed source

Hybrid planning and validation layer for OpenCode. This repository currently contains the reconstructed source bundle as a gzip-compressed tar archive.

## Get the source

Download [`oiol-planner-v0.1.0-reconstructed.tar.gz`](./oiol-planner-v0.1.0-reconstructed.tar.gz) and extract it. The archive contains the complete project directory, source modules, tests, `.env.example`, and documentation.

## Validation

The reconstructed project was tested locally with Node.js: 9 tests passed, 0 failed; CLI syntax and help output passed; the tar archive integrity check passed.

## Provenance and scope

This is a reconstruction from the retained OIOL Planner v0.1.0 design specification because the earlier session's ZIP was no longer available. It is not claimed to be byte-for-byte identical to that earlier archive. Live LLM provider calls and live OpenCode integration have not yet been tested. The planner does not execute project commands or modify scanned repositories.

See `BUILD_REPORT.md` inside the archive for details.
